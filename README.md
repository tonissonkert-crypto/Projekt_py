Lihtne Pythonis tehtud seiklusmäng kasutades tkinter moodulit.
Mängus saad liikuda erinevate ruumide vahel, võidelda monstriga, läbida labürinti ja leida võtme, et lõpuks võita mäng.

Funktsioonid:
1. Monstriga võitlemine
2. surmade lugemine
3. võtme süsteem
4. labürint
5. võiduruum
6. lõksuruum
7. piltide kasutamine

Käivitamine:
1. paigalda python 3
2. Laadi projekt alla(https://github.com/tonissonkert-crypto/Projekt_py/tree/main)
3. Lae alla kõik vajalikud pildid
   monster.png
   monster.pekstud.png
4. käivita mäng

Kuidas mängida:
1. Loe tekste enne nuppude vajutamist
2. Vajuta nuppudele, et liikuda ühest ruumist teisse
3. Võitle monstriga
4. Mine labürinti
5. avasta, et sul on võtit vaja ja mine tagasi algusesse
6. leia õige ruum ja võida

Kasutatud tehnoloogiad:
1. Python 3
2. Tkinker GUI

Võimalikud lisad tulevikus:
1. Rohkem ruume
2. rohkem pilte
3. Rohkem mängija kiusamist troll elementidega
